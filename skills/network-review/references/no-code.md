# If you can't run code here

Tell the person plainly: this environment can't run the bundled scripts, so the results will be rougher.
Offer to (a) continue in an assistant that can run code (Claude Code, Codex, Cursor, the Claude desktop
app), or (b) do a small manual version:

- Reconnect: ask them to list 20 people they were once close to. For each, use the email connector (if
  any) to find the last message, and build the Reconnect list from the quiet ones.
- Cleanup: work through one export at a time in batches of 200 rows; apply the same rules (merge only
  when a shared email/phone AND names agree; remove bounced and automated addresses; ask about
  same-name pairs); produce the import with the exact header of their own Google export.
